UHF RFID Sticker-Tag Reader Module

Our UHF RFID sticker-tag reader module provides high-performance reading of ultra-high frequency (UHF) tags in a compact form factor. Designed for integration into embedded systems, it combines low power consumption with robust long-range detection. Typical applications include inventory tracking, supply chain management, and secure access control.

Features include adjustable operating frequency, support for multiple regional standards, and standard communications interfaces for easy integration into your hardware.

WIFIGATE

WIFIGATE is a robust smart gate-opening system for parking lots, residential complexes, and high-security sites. A single device supports four parallel access channels — Wi-Fi, cellular, offline fallback, and RF remote control — ensuring maximum uptime and speed. The intuitive interface lets you digitally learn a new RF-remote code with one tap, and the user manager enables rapid add/remove operations with CSV import/export. Hardware installs quickly, reduces costs, and an advanced algorithm guarantees instant gate opening under any condition. WIFIGATE is offered in 3 plans, including a free plan with no subscription fees and support for up to 20,000 users.

BYERE BOX — Build Your Escape Room Easily!

BYERE BOX is a universal control box for escape rooms that lets you build rooms and puzzles without needing electronics expertise. It's plug-and-play, so you can focus on designing the story and challenges while the hardware “just works.”

The system features one-button digital RF code learning to pair a new remote in seconds, plus simple I/O for common props:

  • 1 x dry-contact input (e.g., keypad, reed switch, pressure mat)
  • 1 x relay output for locks (including electromagnetic locks), lights, buzzers, or other effects

Install fast, reduce wiring complexity, and keep full control over your puzzles with an intuitive, reliable controller designed specifically for escape rooms.
