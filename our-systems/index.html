Our Systems

UHF RFID Sticker-Tag Reader Module

Our UHF RFID sticker‑tag reader module provides high‑performance reading of ultra‑high frequency (UHF) tags in a compact form factor. Designed for integration into embedded systems, it combines low power consumption with robust long‑range detection. Typical applications include inventory tracking, supply chain management, and secure access control.

Features include adjustable operating frequency, support for multiple regional standards, and standard communications interfaces for easy integration into your hardware.

WIFIGATE

WIFIGATE is a wireless gateway solution that allows secure remote control of gates, doors, or other actuators via Wi‑Fi. It enables you to control access points using a mobile app or web interface, with real‑time status reporting and robust encryption for peace of mind.

The system integrates easily with existing infrastructure and can be configured for scheduled actions, user‑specific permissions, and event logging. Designed for both residential and commercial settings, WIFIGATE delivers convenience without compromising security.

BYERE BOX – Build Your Escape Room Easily!

The BYERE BOX is a modular escape‑room kit designed to make creating immersive puzzle experiences simple. Each box includes a microcontroller, sensor interfaces, and a collection of ready‑made puzzles—such as RFID triggers, keypads, and magnetic sensors—that can be arranged into unique storylines.

Whether for educational purposes, team building, or entertainment, BYERE BOX provides plug‑and‑play components and clear documentation so you can focus on designing the experience, not the electronics.
